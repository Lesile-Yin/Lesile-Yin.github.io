这个简历网站是怎么搭的

下面是构成本站的实际技术，以及我能独立交付的工程能力（对应岗位要求）。本站为单文件原生实现、零框架零构建；交付能力部分为我可落地的全栈 / RAG / 私有化栈。

🧱 本站前端（实际）
  • HTML5 + CSS3 · 变量主题 / 玻璃拟态 / 响应式
  • 原生 JavaScript · 零框架 / 零打包（整站单文件）
  • SVG 内联图标 · 零外部图片依赖
  • IntersectionObserver · 滚动入场与 Dock 联动
🐍 Python 数据管线（实际）
  • python-docx 解析作品集数据
